## 本次发现并修复

1. 外文source字幕原先挡住另一路可用中文字幕：现在按语言筛选可用中文候选。
2. 只有空格的标题原先可能被保存：现在拒绝，没有成品。
3. SRT分钟或秒数超过59原先未独立检查：现在拒绝无效时间。
4. 字幕首尾相近但中间缺一大段，原先没有明确提示：现在报告最大空档，超过10秒先partial并核对。空档可能是正常静默，不自动补句或宣称丢字。

新增测试先复现这些问题，再修复并全量回归。32项包含原有23项及9项新增检查；测试数量不是视频数量。
