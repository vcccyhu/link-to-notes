# 首次启动、跨窗口复用与权限

## 为什么导入了还会失败

Skill说明、Python依赖、当前会话权限、网络连接是四个不同条件。导入说明不安装依赖；扩大权限不会修复旧Python、缺包、DNS或TLS。不能只凭报错文字认定权限原因。先运行检查，记录实际执行路径、失败阶段和错误类型。

## 一次设置，后续复用

在Skill目录使用可执行的Python运行：

```sh
python scripts/bootstrap.py --setup
python scripts/bootstrap.py --check
python scripts/bootstrap.py --run collect_link -- '完整分享文案'
```

bootstrap仅依赖标准库，能从当前或常见命令位置寻找Python 3.10以上，创建Skill目录内.venv并安装requirements.txt；找不到时明确说明需要安装Python，不下载陌生运行器。系统命令可能是python3或Windows的py。setup会访问Python包仓库、消耗磁盘，只有首次或依赖损坏需要执行。只读check不安装，使用临时测试文件检查已有素材目录能否写入并立即清除；显示实际失败类型。

.venv不随ZIP或GitHub分发。同一电脑同一个安装目录的新窗口复用该环境，不依赖聊天记忆。重新安装到另一个位置或换电脑要重新setup；现有素材库配置和笔记不覆盖。无音频字幕时才按需运行setup --asr安装额外转写依赖，并另行提供ffmpeg/ffprobe。

## 必需与可选权限

| 能力或位置 | 用途 |
| --- | --- |
| 执行本地程序、读取Skill目录 | 运行处理程序 |
| 写Skill目录内.venv、首次设置文件 | 创建独立环境；初始化时保存配置 |
| 读写用户选择的素材库 | 保存和回读笔记、图片、索引 |
| 写系统临时目录 | 暂存网页、音视频，处理后清理 |
| 终端联网到小红书页面与图片/字幕/媒体域名 | 获取用户提交的内容 |
| 首次安装联网到包仓库；可选模型下载 | 安装依赖，按需转写 |

不需要管理员权限、全盘访问、密码、Cookie导出、GitHub写权限或摄像头麦克风权限。浏览器后备是否另需扩展、屏幕访问等取决于宿主；只有真正使用时说明和申请，不把“全部开放”当安装要求。系统保护目录可能需要用户对所选文件夹授权，Skill不能代替宿主授予。

## 网络与权限分开诊断

DNS失败、TLS断连、HTTP拒绝与PermissionError分别记录。网络许可不保证连接成功，宿主不同会话的有效权限也不能由另一个窗口推断。正常请求失败时按workflow继续真实浏览器诊断；本机已有确定证据的网卡选项可用 `python scripts/bootstrap.py --remember-interface 本机接口名` 保存。程序验证接口存在，保存于.venv/xhs-network.json，仅应用于collect_link；不改系统路由、代理或证书设置。是否有效还需真实链接验证。接口失效时修正本机选项，不复制别人的en0；需要清除时删除这一个本机偏好文件。

除显式指定接口外，现有采集不访问公共DNS解析服务；指定接口时Fetcher会向Cloudflare/Google的DoH解析目标域名，不发送笔记正文或登录数据。机构限制该服务时不得绕过限制，应使用获准网络或浏览器路径。

## 可运行范围

只有聊天功能、不能运行本地程序或写文件的手机AI不能靠安装包获得这些能力。本版本是电脑本地工作流，手机可发送链接给具备能力的电脑环境处理。Windows需要真实设备测试，不将路径适配等同验收。遇登录或验证码由使用者在平台完成，不保证所有内容可访问。

## 更新同步

发布源目录、本机安装目录和GitHub是三份独立副本，编辑一处不会自动更新另两处。更新时验证、同步并对比文件，再发布新版本；旧版固定Release不会变成新版。正在进行的会话可能已加载旧说明，应让它重新读取完整SKILL.md，必要时重新打开会话。不能声称替它修改了宿主权限。

## 0.2.3：复用已验证的请求选项

Markdown分享链接现在由input_url直接识别，不需要用户手动删去方括号；签名查询参数保持原字节。普通分享文本与纯链接继续支持。

仅当本机诊断已证明直连合法且有效，并且用户或机构允许时，可执行 `python scripts/bootstrap.py --remember-interface 本机接口名 --remember-no-proxy`。这把接口与小红书相关域名的代理例外存入本Skill的.venv/xhs-network.json；后续通过bootstrap运行collect_link自动复用，仅作用于该子进程，不更改系统代理或其他脚本。不使用通配符，不自动复制到别人电脑，不用于绕过宿主网络控制。只保存接口的旧偏好继续可用。需要清除时删除该本机偏好文件。

这只解决复用请求选项，不保证所有网络或平台访问成功。模型未知错误与旧会话重复执行是宿主问题，本版增加明确停止和收尾规则，不将其宣称为已根治。
