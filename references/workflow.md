# 获取、后备处理与验收

## 正常路径

`collect_link.py` 从整段分享文本提取小红书链接，逐跳保留参数，使用移动端公开页面。支持状态结构 `noteData.data.noteData`、`note.noteDetailMap[ID].note`。发布时间取 `time` 而非 `lastUpdateTime`；点赞为快照，18.2K等展示值不能伪造为精确数。

取得视频绑定的中文字幕后，检查SRT格式、排序、首尾覆盖，压缩封面到长边不超过720像素，写入笔记及索引。JSON标量写法是有效YAML；后续读取必须用YAML解析，因为Obsidian可能重排属性。

首尾相近不证明中段无漏句。程序报告最大内部空档，超过10秒先标记partial，待核对音频后再决定是否确有漏句。首次验收、怀疑目标不对应或字幕异常时，还要取得真实媒体核对时长并抽查首中尾，留意长时间无文字的区间。纯音乐、静默和暂停可能造成正常间隙，不能凭空补话。

## 页面或网络失败

1. 区分短链跳转、验证页、缺详情、媒体获取、识别、保存各阶段，保留具体缺项。
2. 直接请求为空不代表视频不存在。宿主有浏览器工具时，用真实浏览器打开原分享链接，核对目标标题、作者、ID和时长。遵循该宿主工具的权限要求，不绕过验证或导出登录凭据。
3. 页面能播放而video标签为blob时，查看实际媒体请求。只处理已观察到的目标媒体；不要猜接口或将登录信息交给外部解析站。无浏览器能力时诚实报告能力缺口。
4. 某网络环境发生TLS断连，且已确认本机接口时，可显式使用 `--interface '已核实接口名'`；这是可选排查路径，不是安装要求。DoH查询会发送待解析域名到公共解析服务；普通路径不使用此选项。不关闭证书校验，不改系统代理、路由或hosts。

## 无中文字幕：真实音频后备

本版采集脚本不会自动切换；此段由智能体执行。先找到真实音频/视频资源，下载到本次任务临时目录。确认资源合法可访问且来源ID对应；不要从简介生成假文字稿。

1. 使用ffprobe取得媒体时长，确认存在音轨；ffmpeg完整解码音轨，避免只下载到首段。
2. 有必要时安装可选转写依赖和ffmpeg；只在已有媒体且确需转写时下载模型。
3. 从Skill目录执行，输入和输出使用本次任务临时目录的绝对路径：

```sh
python scripts/transcribe.py '临时视频或音频' --out '临时目录/transcript.txt' --language auto
```

可指定 `--language zh` 或 `en`，质量不足可选 `--model small`。ffmpeg转为16kHz单声道PCM数组后提供给模型，避免已遇到的PyAV文件解码参数不兼容。模型在任务临时目录，正常退出自动清理；依赖缓存可能仍存在。不要通过环境变量把模型缓存指向长期素材目录。

4. 核对正文首中尾和疑似漏识别区间；视频有画面字幕时可辅助OCR，但抽帧OCR也可能遗漏短字幕。标明来源和校对范围，不宣称逐字人工稿；疑似缺句且无法核对时记录partial，不提交为完整稿。
5. 从实际页面准备metadata JSON（`collect.metadata()`的字段结构），至少有id/title/author/source_url/published_at/likes/collected_at，填原始share_url。来源ID必须和页面匹配。
6. 保存：

```sh
python scripts/collect.py save --metadata '临时目录/metadata.json' --transcript '临时目录/transcript.txt' --cover '临时目录/cover.jpg' --root '用户素材库' --method '本地Whisper自动识别；填写实际校对范围'
```

7. 只有回读通过并完成正文内容检查才向用户报成功。保留待处理记录直到缺项解决。清理任务自建临时文件，不清用户已有资料。

## 文件与元数据验收

- 标题和作者对应这条来源，视频ID用于去重；同标题同作者也不能覆盖另一条素材。
- 发布和采集时间分开；平台只显示分钟时注明精度，不假造秒。
- 封面可解码、相对路径存在；文字无编码替换字符。
- 字幕正文不是作者介绍、评论、章节摘要或相关推荐。
- 保存结果分 `saved`、`partial`、`already_saved`、`failed`；打印saved只代表程序保存，智能体仍要完成内容验收。
- 摘要和导航是可选AI整理，不能替代全文，也不能把推测写成原话。
